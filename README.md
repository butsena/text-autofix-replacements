# Словарь замен

Public-репозиторий для плагина **Text Autofix** (Циан).

Здесь курируемые правила автоматических замен: исходный вариант → канонический текст, с типом правила.

Плагин при запуске скачивает файл `text-replacements.csv` с GitHub.  
Пересобирать плагин после правок **не нужно**.

---

## Файл

| Файл | Назначение |
|---|---|
| `text-replacements.csv` | Правила замен: `тип,исходные варианты,верный текст,формы` |

## Формат CSV

Первая строка — заголовок:

```csv
тип,исходные варианты,верный текст,формы
```

Дальше строки вида:

```csv
exact,далее,дальше,
join,"он-лайн, он лайн",онлайн,
spell,риэлтор,риелтор,
lemma,приобрести,купить,приобрела=купила; приобрели=купили
phrase,денежные средства,деньги,денежных средств=денег
```

Колонки:

| Колонка | Обязательно | Смысл |
|---|---|---|
| **тип** | да | `exact` · `spell` · `join` · `lemma` · `phrase` · `special` |
| **исходные варианты** | да | Через запятую (для `spell`/`join` — основа слова). Имена колонок как в старом словаре — так работают и уже опубликованные сборки плагина. |
| **верный текст** | да | Один канонический текст (нижний регистр) |
| **формы** | для `lemma`/`phrase` | Пары словоформ: `было=стало; а\|б=в` |
| **пояснение** | нет | Комментарий для редакторов, плагин его не применяет |

Не переименовывайте **исходные варианты** / **верный текст** в «найти» / «заменить»: старый плагин тогда начинает читать колонку **тип** как исходное слово и перестаёт править «он-лайн», «риэлтор» и остальные.

### Типы правил

| тип | Когда | Пример |
|---|---|---|
| `spell` | Меняются буквы корня, окончания те же | `риэлтор → риелтор` (все падежи сами) |
| `join` | Дефис/пробел → слитно, окончания те же | `промо-код, промо код → промокод` |
| `exact` | Одна точная замена | `далее → дальше`, `тыс. → тыс` |
| `special` | Особый символ или сжатие | `рубль, рубля, рублей, руб. → ₽` |
| `lemma` | Синоним с другой парадигмой | `приобрести → купить` + колонка **формы** |
| `phrase` | Многословная замена с формами | `денежные средства → деньги` + **формы** |

Правила:

1. Регистр **не дублируйте**: достаточно `далее → дальше`. В новой сборке плагина сработает и «Далее», и «ДАЛЕЕ».
2. Несколько исходных вариантов — через запятую в одной ячейке (в кавычках, если есть запятые).
3. В колонке **верный текст** — **один** правильный вариант в нижнем регистре.
4. Колонка **формы** нужна, когда у синонима другая словоизменительная парадигма. Несколько пар разделяйте `;`, варианты написания слева — `|`.
5. Сопоставление — целое слово или фраза по границам кириллицы.
6. Не меняйте имя файла и названия колонок.

## Как править редактору

### Вариант А — через сайт GitHub (проще)

1. Откройте файл:  
   https://github.com/butsena/text-autofix-replacements/blob/main/text-replacements.csv
2. Нажмите карандаш (**Edit**).
3. Добавьте или измените строку.
4. Внизу: **Commit changes** → сохраните в ветку `main`.

### Вариант Б — через Pull Request

Если нет прямого доступа на запись в `main` — создайте PR с правкой CSV. После merge плагин подхватит изменения сам.

---

## Проверка

После сохранения откройте плагин Text Autofix в Figma на любом тексте с вашей заменой.  
В блоке **«Техническая хрень»** строка **«Словарь замен»** должна показывать загрузку с GitHub.
