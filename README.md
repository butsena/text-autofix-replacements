# Словарь замен

Public-репозиторий для плагина **Text Autofix** (Циан).

Здесь лежит список автоматических замен текста: неправильный или устаревший вариант → правильный.

Плагин при запуске скачивает файл `text-replacements.csv` с GitHub.  
Пересобирать плагин после правок **не нужно**.

---

## Файл

| Файл | Назначение |
|---|---|
| `text-replacements.csv` | Пары «исходные варианты → верный текст» |

## Формат CSV

Первая строка — заголовок:

```csv
исходные варианты,верный текст
```

Дальше строки вида:

```csv
"далее, ДАЛЕЕ",дальше
Далее,Дальше
"он-лайн, он лайн, ОНЛАЙН",онлайн
```

Правила:

1. Несколько исходных вариантов пишите через запятую в одной ячейке (в кавычках).
2. В правой колонке — **один** правильный вариант.
3. Учитывайте регистр: отдельно строчные и варианты с заглавной, если нужны оба.
4. Не меняйте имя файла и заголовок колонок.

---

## Как править редактору

### Вариант А — через сайт GitHub (проще)

1. Откройте файл:  
   https://github.com/butsena/text-autofix-replacements/blob/main/text-replacements.csv
2. Нажмите карандаш (**Edit**).
3. Добавьте или измените строку.
4. Внизу: **Commit changes** → сохраните в ветку `main`.

### Вариант Б — через Pull Request

Если нет прямого доступа на запись в `main` — создайте PR с правкой CSV. После merge плагин подхватит изменения сам.

---

## Проверка

После сохранения откройте плагин Text Autofix в Figma на любом тексте с вашей заменой.  
В блоке **«Техническая хрень»** строка **«Словарь замен»** должна показывать загрузку с GitHub.
